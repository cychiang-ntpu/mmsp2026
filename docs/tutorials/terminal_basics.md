# 終端機基本操作入門

寫 C 程式一定會用到終端機（Terminal）——那個打指令的黑色視窗。
這份文件教你最基本的生存技能：知道自己在哪、怎麼移動、怎麼執行程式。

## 什麼是終端機？

平常你用滑鼠點資料夾、點兩下開程式；終端機做的是**同一件事**，
只是改成「打字下指令」。在 VSCode 裡按 `` Ctrl+` ``（Ctrl 加左上角反引號）
就能打開內建終端機。

> Windows 的終端機預設是 **PowerShell**，本文件以它為準；
> macOS / Linux 的同學看各段落的補充說明即可，指令大同小異。

---

## 觀念 1：你永遠「站」在某個資料夾裡

終端機隨時有一個**目前所在資料夾**（工作目錄），
提示符號上就寫著，例如：

```
PS C:\Users\student\hello_c>
```

代表你現在站在 `C:\Users\student\hello_c` 裡。
你下的指令（例如編譯、執行）都是**對這個資料夾裡的東西**做的。
新手最常見的錯誤就是：**人站錯資料夾，卻在找檔案**。

---

## 三個最重要的指令

| 指令 | 意思 | 範例 |
|------|------|------|
| `pwd` | 我現在在哪？（印出目前路徑） | `pwd` |
| `ls` | 這裡有什麼？（列出資料夾內容） | `ls` |
| `cd` | 移動到別的資料夾 | `cd hello_c` |

（`ls` 在 Windows 舊的 cmd 裡叫 `dir`；PowerShell 兩個都能用。）

`cd` 的三種常見用法：

```
cd hello_c        進入目前資料夾底下的 hello_c
cd ..             回到上一層（.. 代表上一層資料夾）
cd C:\Users\student\hello_c    直接跳到完整路徑
```

> 路徑含**空白**時要加引號：`cd "My Folder"`。
> 這也是為什麼建議資料夾名稱不要有空白和中文。

---

## 觀念 2：執行程式要加 `.\`

編譯出 `hello.exe` 之後，執行它要打：

```
.\hello
```

開頭的 `.\` 意思是「**目前這個資料夾裡的** hello」。
（`.` 代表目前資料夾，就像 `..` 代表上一層。）
只打 `hello` 在 PowerShell 會找不到——這是安全設計，不是你打錯。

macOS / Linux 同理，只是斜線方向相反：`./hello`。

## 四個省力神技（一定要學！）

| 按鍵 | 功能 |
|------|------|
| `Tab` | **自動補齊**：打 `cd hel` 按 Tab，自動補成 `cd hello_c`。檔名再長都不用打完，也不會打錯字 |
| `↑` / `↓` | 叫回**之前打過的指令**，改都不用改直接按 Enter 重跑。編譯→執行→編譯→執行就靠它 |
| `Ctrl+C` | **強制中斷**正在跑的程式。程式進入無窮迴圈跑不停時的救命鍵 |
| `cls`（或 `clear`） | 清空畫面，眼睛清爽 |

## 常用指令速查

| 想做的事 | 指令 |
|------|------|
| 我在哪 | `pwd` |
| 列出檔案 | `ls` |
| 進入資料夾 | `cd 資料夾名` |
| 回上一層 | `cd ..` |
| 建立資料夾 | `mkdir 新資料夾名` |
| 看文字檔內容 | `cat 檔名` |
| 複製檔案 | `cp 來源 目的`（cmd 用 `copy`） |
| 刪除檔案 | `rm 檔名`（**小心！沒有資源回收桶**） |
| 編譯 C 程式 | `gcc hello.c -o hello` |
| 執行程式 | `.\hello` |
| 查自己的 IP | `ipconfig`（macOS/Linux 用 `ifconfig`） |
| 強制停止程式 | `Ctrl+C` |

## 常見狀況排解

**「找不到檔案」或編譯說 `No such file or directory`？**
先 `pwd` 看自己在哪，再 `ls` 看檔案到底在不在這裡。
八成是站錯資料夾——`cd` 過去就好。

**在 VSCode 用「開啟資料夾」打開專案，終端機就會自動站在專案資料夾。**
所以養成習慣：永遠用 `File > Open Folder` 開資料夾，不要只開單一檔案。

**打了指令沒反應、游標一直閃？**
程式可能正在等你輸入（例如 `scanf`），輸入資料按 Enter；
或它在跑無窮迴圈——按 `Ctrl+C` 中斷。

**畫面出現中文亂碼？**
輸入 `chcp 65001` 把編碼切成 UTF-8 再重跑一次。

## 練習

打開終端機，依序完成：

1. `pwd` 看自己在哪。
2. `mkdir practice` 建一個資料夾，`cd practice` 進去。
3. `cd ..` 回上層，再用 `cd pra` + `Tab` 補齊回去。
4. 按 `↑` 叫回剛剛的指令看看。
5. 在裡面寫一個 hello.c，編譯並用 `.\hello` 執行。

全部做完，你的終端機生存技能就及格了！
