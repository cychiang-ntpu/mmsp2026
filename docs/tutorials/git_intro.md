# Git 入門：幫你的程式設「存檔點」

玩遊戲打王之前會先存檔，死了可以讀檔重來。
**Git 就是程式碼的存檔系統**：每完成一小步就存一個「存檔點（commit）」，
改壞了隨時可以回到上一個能動的版本，再也不用複製 `hello_最終版2_真的final.c`。

## 安裝 Git

1. 前往 <https://git-scm.com/download/win> 下載 Windows 安裝檔。
2. 執行安裝，全部保持預設值一路下一步即可。
3. 裝完**重開 VSCode**，在終端機輸入驗證：

   ```
   git --version
   ```

   看到 `git version 2.x.x` 就成功了。

4. 第一次使用要自我介紹（存檔點會記錄是誰存的），只需做一次：

   ```
   git config --global user.name "你的名字"
   git config --global user.email "你的學校信箱"
   ```

---

## 核心觀念：三個步驟一個循環

```
改程式 → git add（把改動放上「待存清單」） → git commit（正式存檔）
   ↑                                                      |
   └──────────────────── 繼續開發 ←─────────────────────────┘
```

- **add**：告訴 Git「這次我要存哪些檔案」。
- **commit**：真正建立存檔點，並附一句話說明這次做了什麼。

---

## 實際操作：第一次存檔

在 VSCode 打開你的專案資料夾（例如 `hello_c`），在終端機依序輸入：

```
git init                        # 1. 讓這個資料夾開始被 Git 管理（只做一次）
git add hello.c                 # 2. 把 hello.c 放上待存清單
git commit -m "完成 hello world"  # 3. 存檔！-m 後面是這次的說明
```

之後每完成一個小進度就重複 2、3 步：

```
git add .                       # 「.」代表這次改過的全部檔案
git commit -m "加入成績計算功能"
```

> 存檔說明寫「做了什麼」：好的例子「修好除以零的 bug」；
> 壞的例子「改了一些東西」「aaa」。未來的你會感謝現在的你。

## 查看狀態與歷史

```
git status      # 現在有哪些檔案改過還沒存？（最常用，隨時打）
git log --oneline   # 列出所有存檔點，一行一個
git diff        # 具體看改了哪幾行（按 q 離開）
```

`git log --oneline` 的輸出長這樣：

```
a3f9c21 加入成績計算功能
b71e0d4 完成 hello world
```

前面的英數字（如 `a3f9c21`）是每個存檔點的編號。

## 讀檔：改壞了怎麼救回來

**狀況一：檔案改爛了，想放棄這次的修改，回到上次 commit 的樣子**

```
git restore hello.c
```

> 注意：這會**丟掉**還沒 commit 的修改，下之前想清楚。

**狀況二：只是想看看之前某個版本長怎樣**

```
git log --oneline          # 先找到那個存檔點的編號
git show b71e0d4:hello.c   # 顯示那個版本的 hello.c（按 q 離開）
```

這就是 Git 的安全網：**只要有 commit，程式碼就永遠救得回來。**
所以口訣是：**小步快存，常常 commit。**

## 用 VSCode 圖形介面操作（不想打指令的話）

VSCode 左側的「原始檔控制」圖示（三個圓圈連線，`Ctrl+Shift+G`）
就是 Git 的圖形介面：

- 改過的檔案會列在面板中，檔名旁有 `M`（修改）或 `U`（新檔案）。
- 按檔案旁的 **+** 就是 `git add`。
- 上方輸入框打說明文字，按 **Commit** 按鈕就是 `git commit`。
- 點檔名可以並排比對改了哪些行（左邊舊、右邊新）。

指令和圖形介面做的是同一件事，用哪個都可以。

## 該忽略的檔案：.gitignore

編譯產生的 `.exe`、`.obj` 不需要存檔（隨時可以重新編譯出來）。
在專案資料夾建立一個名為 `.gitignore` 的檔案，內容：

```
*.exe
*.obj
*.o
```

之後 `git status` 就不會再列出這些檔案了。

## 常見問題

**Q1：commit 時跳出一個奇怪的編輯器畫面？**
你忘了加 `-m "說明"`。輸入 `:q!` 按 Enter 離開，重新下一次指令。

**Q2：`git status` 說 `not a git repository`？**
這個資料夾還沒 `git init`，或你站錯資料夾了（先 `pwd` 確認）。

**Q3：commit 說 `nothing to commit`？**
忘了先 `git add`，或檔案根本沒改（忘了存檔 `Ctrl+S`？）。
