jitter buffer 動畫：Team 2 接收端怎麼「永遠不等」

送端每 20 ms 送一包（seq 0, 1, 2, …），網路隨機延遲／遺失／亂序／重複；收端的播放時鐘照樣每 20 ms 交出一個 frame——有就播、沒有就 PLC 補。計數規則照 Team 2 README 的 STATS；JS 裡每條規則旁邊都有註解，可以對照你們的 C。

封包（在路上／在 buffer）播出PLC 補的遲到丟掉重複丟掉網路弄丟

鍵盤：空白鍵 播放／暫停、→ 單步、R 重設、S 掃描。

buffer 掃描：同一個 seed，buffer 從 0 掃到 200 ms

用目前的 jitter／loss／reorder／dup／seed，每個 buffer 值完整跑一次，畫 late、concealed、avg_delay_ms。

網路與 buffer

改任何參數都會重新產生同一個 seed 的隨機序列並重設。網路延遲 = uniform(0, jitter)；reorder = 這一包額外再多等 30 ms；dup = 多送一份、各自有延遲。
