同一段聲音，換取樣率與 bit depth 再聽一次

        

          
          
          
        

        

        
        

        
降低取樣率 → 高頻不見，聲音變「悶」；不先濾波就降取樣 → 高頻折回來變成原本沒有的怪聲（aliasing）。
          降低 bit depth → 多了「沙沙」的量化雜訊，小聲的地方最明顯；8 bits 以下，聲音小到一個程度會整個消失（被量化成 0）。
          為了讓瀏覽器能播放，改過的聲音會再內插回原本的取樣率，但資訊已經少了。

BMP 也是 little-endian。檔頭之後就是 pixel：每個 pixel 3 bytes，順序是 B、G、R（不是 R、G、B）；
          而且高度為正時，第一列資料是圖的最下面一列（由下往上存）。每一列的 bytes 數要補到 4 的倍數。

圖像的「取樣」是空間上的：解析度就是取樣率，降低它，圖就變成一格一格（和聲音的取樣點一樣）。
          每個顏色的 bits 就是 bit depth：降到 3–4 bits，天空、海洋這種緩慢變化的地方會出現一條一條的「色帶」——那就是看得見的量化誤差。
