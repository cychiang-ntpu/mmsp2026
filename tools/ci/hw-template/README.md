## 怎麼用

- 程式放在 `mp1/` … `mp5/`，每個資料夾裡的 README 有規則。
- 每次 `git push`，GitHub Actions 會自動編譯並和 Python 參考實作比對，結果在上方 **Actions** 分頁。
- 本機測試：把課程 repo clone 在旁邊，執行 `bash ../mmsp2026/tools/ci/run_tests.sh`。
- 完整說明：課程 repo 的 [docs/tutorials/github_actions_ci.md](https://github.com/cychiang-ntpu/mmsp2026/blob/main/docs/tutorials/github_actions_ci.md)。
